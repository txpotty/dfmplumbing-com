    PEX-A, PEX-B, and PEX-C Systems in Southaven, MS

    There are three grades of PEX, named for how the plastic is cross-linked at the factory. PEX-A bends the easiest and uses expansion rings, PEX-B is stiffer and uses crimp rings or cinch clamps, and PEX-C handles more like B. Every one is listed for potable water. We match the pipe to the fittings and tools from one maker so the warranty stays intact.

    PEX-A vs. PEX-B Installation in Southaven

    Homeowners ask us which one is better, and it really depends on the house. PEX-A makes tighter bends, can be heat-fixed if it kinks, and its fittings flow better, while PEX-B is cheaper and its crimps hold just as well when each one is gauged. Both last decades. In a cramped attic, we usually pick PEX-A.
