    While it's possible for a handy homeowner to replace a garbage disposal, it involves working with both electricity and plumbing, which can be hazardous if not done correctly.     Key signs you need a new garbage disposal include persistent leaks from the unit's housing, a humming noise without grinding, frequent clogs despite proper usage, foul odors that won't go away, or if the unit simply won't turn on.
