    Old Urinal Removal and Replacement in Madison

    Old urinals come off harder than they went on. Rusted bolts and seized valves often have to be cut, so we protect the tile while working. New gaskets always go in. The flange gets cleaned to bare metal.

    Sloan Flush Valve Installation in Madison, MS

    Sloan Royal valves are on most commercial urinals we see. Each Sloan Royal gets the right inside parts for the bowl, a tuned control stop and a rebuild kit on hand. Sensor versions mount the same way. Battery models need no wiring.

    Waterless Cartridge Urinals in Madison

    Each waterless brand uses its own cartridge. Falcon, Waterless Co, Kohler and Zurn units all trap odor differently, and the cartridge or sealing liquid has to be replaced after a set number of uses, which in a busy restroom can mean every few months. We set up a schedule with you. Spare cartridges should stay on site.

    Urinal Replacement and Upgrades in Madison

    Cracked or stained urinals are worth replacing. Cracked china leaks eventually and heavy scale rarely comes clean, so a new bowl on the old carrier is usually best. We check the carrier bolts first. Rusted bolts get replaced.

    Flushometer Urinal Installation in Madison

    Manual flushometers are still the most common setup. We install Sloan Royal or Zurn AquaFlush valves on a 3/4 inch supply, adjust the control stop for proper flow, and set the vacuum breaker the right distance above the bowl so it protects the drinking water. Handles can go left or right. ADA units need the handle within reach.

    Waterless Urinal Upgrades in Madison

    Switching to waterless is mostly a fixture swap. We remove the flush valve, cap the supply and set the waterless bowl on the same carrier. Some codes want the supply left in place. That allows a future change back.

    Home Gym and Garage Urinals in Madison, MS

    A garage urinal saves tracking dirt into the house. The drain ties to the nearest stack, a vent or AAV goes in where allowed, and a compact bowl fits the space. Freeze protection matters in garages. Ask us about the layout.

    Flush Valve Urinal Installation in Madison, MS

    Flush valve urinals are the commercial standard. Tankless flushometers deliver a set volume from a 3/4 inch line and recover instantly for the next user. The volume matches the fixture rating. Wrong settings stain bowls.
