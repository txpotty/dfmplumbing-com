The discharge gets carried well away from the foundation so the same water is not pumped twice.

    PEX Pipe Installation in Ridgeland, MS

    PEX bends around corners, shrugs off corrosion and needs far fewer fittings than copper. That stretch is not a license to skip insulation, so exterior-wall and crawl-space runs still get wrapped.
